# Projeto: Morfeu

**Engenheiro:** Arthur (Senior · CTO)

## Visão

O projeto-template da área: clona-se e deriva-se novos produtos rapidamente, com a base
mais difícil já implementada. O Morfeu não é um produto vendido — é a **base comum** que
dá velocidade a todos os outros projetos.

## Como funciona

- Backend declarativo em **Ash Framework + Phoenix** (Elixir): macros declaram recursos
  do Ash (domínios) e todo o resto do backend é derivado.
- Todo projeto novo da CIS começa clonando o Morfeu — ver [stack.md](../stack.md).

## Regras

- Mantido pelo CTO. Mudanças na base comum afetam todos os projetos — só entram com
  alinhamento com o CTO.
- Melhorias descobertas dentro dos projetos que sejam genéricas devem voltar para o
  Morfeu, para beneficiar os próximos clones.

## Estado atual

- É a base do LM Zello e dos próximos projetos.
